# Interactive Web Generator

Want to customize your GitHub Profile stats without messing around with terminal flags? We built a dedicated, zero-latency static web generator to make styling your README effortless.

**[Launch the TakaTime Stats Generator](https://rtarun3606k.github.io/TakaTime/)**

###  How to Use It

1. **Pick a Base Theme:** Choose from our 15+ built-in palettes (like Tokyo Night, Catppuccin, or Dracula) using the dropdown menu.
2. **Fine-Tune the Colors:** Want a specific neon accent to match your aesthetic? Use the color override pickers to manually adjust the background, text, and progress bar hex codes.
3. **Copy the Code:** Once your Live Preview looks perfect, click the **Copy Command** button. It will instantly generate the exact `./taka-report` CLI command you need to drop into your GitHub Actions workflow.

###  Features
* **Live Preview:** See exactly what your stats card will look like before you commit any code to your repository.
* **100% Client-Side:** Just like the core TakaTime architecture, this generator respects your privacy. All customization and preview rendering happens locally in your browser. No data is sent to any remote server.
